• /usr: Tempat aplikasi global disimpan (seperti /usr/bin/ls, /usr/share/fonts). Anda butuh sudo pacman -S untuk memasang aplikasi di sini.
• /etc: Tempat semua konfigurasi global sistem (seperti pengaturan jaringan internet, bluetooth, atau hak akses user).
• /sys dan /proc: Tempat jantung Kernel Linux dan hardware dipetakan.
